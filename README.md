# Versao Desktop - Plataforma de Gestao Escolar

Esta pasta contem uma versao desktop do sistema usando Electron.

## Como executar

1. Instale o Node.js, se ainda nao estiver instalado.
2. Abra o terminal nesta pasta:

```bash
cd desktop
```

3. Instale as dependencias:

```bash
npm install
```

4. Inicie o aplicativo:

```bash
npm start
```

## Observacoes

- Esta versao nao depende da API PHP nem do PostgreSQL.
- Os dados sao salvos localmente pelo Electron.
- O aplicativo possui alunos, disciplinas, professores, matriculas, notas e boletim.
